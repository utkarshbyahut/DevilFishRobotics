# Front Stereo Experiments

This folder holds front-camera stereo prototypes that are intended for the analyst computer.

The current SGBM script loads `left_map_x.npy`, `left_map_y.npy`, `right_map_x.npy`, and `right_map_y.npy` from the current working directory. Because the script was added without changing its logic, keep those calibration files available in the directory you run it from.
